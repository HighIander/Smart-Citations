Smart Citations options

Configure author matching, journal PDF links, and desktop access.

Used to fill the automatic “My authorships” and “My co-authorships” bibliography categories. Enter your full published name; abbreviated first names are matched automatically.

Use ORCID’s official sign-in and authorization screen. Smart Citations receives the authenticated ORCID iD and loads the public name and affiliations; the user never types an ORCID iD.

No ORCID account linked.
Automatic checks run at most once per day.

These constrain ambiguous name-based OpenAlex matches and filter the author-impact metrics to works where the linked author has one of these affiliations. They are filled from public ORCID affiliations when available and can be edited.

Used to retrieve citation counts and author-impact statistics. OpenAlex API keys are free; create or copy yours from OpenAlex. The key is stored only in this browser's extension storage.

Use this only when you prefer to pin the impact panel to a specific OpenAlex profile instead of the linked ORCID account.

Define domains where to watch for manuscripts. You will be prompted to let you add the manuscript to the Smart Citations database upon opening a PDF file on one of these domains. Enter one hostname or page pattern per line. Wildcards are supported; for example, *.nature.com includes Nature subdomains and the main domain. Lines beginning with # are ignored.

You can see when Smart Citations detects a journal page—the extension icon in the toolbar will show a green checkmark: ✓

Define domains where Smart Citations should hook into CollabTeX-compatible document editors. Enter one hostname per line. Wildcard subdomains are supported; for example, *.example.org includes the main domain and all of its subdomains. CollabTeX at Helmholtz and Overleaf are enabled by default. Lines beginning with # are ignored.

“Remember my choice” in the journal-page dialog changes this setting.

Write errors are always shown and cannot be disabled.

Desktop launcher

Open Smart Citations directly from a bookmark, desktop shortcut, or app-style browser window.
